Create panel — v2 concept

One direction, four screens. The idea in a sentence: every task answers three questions before you type anything — will this work, what will it run on, what will it cost — and every screen is the same skeleton: back → run-line → one big input → smart-default chips → “More” for everything else → one button. Robust underneath, one obvious path on top.

01 · Home — tiles that tell you their state

Same grid, but each tile carries a readiness dot and unready tiles say what they need. No more clicking Deepfake to find out Yapper was never connected. Tiles stay 3/2/1-responsive.

› create
  • status dots — green: connector present and credentialed. Grey + “needs X”: tile still opens, but its screen leads with a one-tap “Connect Krea →” that jumps straight to Settings › Connectors.
  • free tools stay green always — Isolate audio, Upload, Link run on local ffmpeg/disk and never depend on a connector.
  • no agent card here — the link-check diagnostic moves to Settings; Home is tasks only.

02 · Task screen skeleton — the run-line

Every generate screen opens with a run-line: which connector/model this will run on and the cost tier, resolved live from what's installed. The prompt is the hero. Everything else — resolution, duration, connector override — folds into More options. After Generate, the screen doesn't vanish: a progress row confirms the node landed on the canvas, with a jump link.

  • run-line — resolves the tier routing visibly: video defaults to muapi, production image says “midjourney via muapi · $$$”, storyboard image says “gemini · $”. The routing stops being invisible policy and becomes a label.
  • smart defaults up top — only the two choices that change every time (aspect, length). Resolution, connector override, model hint live in More options.
  • result row — Generate no longer silently returns home; the row tracks rendering → ready → failed (with the reason), and “view” pans the canvas to the node.

Voice rows parsed into a list — name, tags, a ▶ preview per row, tap to select. Search filters the user's ElevenLabs library (that's what search_voices actually searches). Music and SFX gain the two knobs their tools really have: length, and 0.5–5s duration.

04 · Motion graphics — a stepper you can walk

The six stages become a visible dot-stepper: done stages are green and clickable to go back, the current stage is bold, future stages are grey. No dead ends, and you always know where you are in the workflow.

05 · What this costs to build

Nothing here is architectural — the plumbing from this round already supports all of it. Status dots read the existing connectors list; the run-line is a label over routing that already happens; the voice rows need one structured parse with a raw-text fallback; the result row is a store field the generate flow already knows; the stepper is navigation state the wizard already tracks. This is a skin over working machinery, which is exactly where a redesign wants to be.
