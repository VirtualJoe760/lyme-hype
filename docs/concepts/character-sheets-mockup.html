Asset Library & Sheets

Five screens for the character/location pipeline, drawn inside the app shell you already have and using theme.css's own tokens. Assets are the real ones from Wow Generations. Green markers are new surfaces; grey markers are things that already exist and get reused.

The Library is a fourth tab, not a Settings page. Trained styles live in Settings because they're configuration; this is working material you open fifty times a session.

Each chip binds to the role its kind implies. You write a sentence; the app assembles a correctly-typed multi-reference call underneath.
Chips carry a role, not just a pathA character chip means “preserve this likeness”; a style chip means “match the look, not the content”. Both are existing fields.
Dialogue gets tagged tooA line followed by a voice chip. Skip it and a multi-character scene starts mixing voices halfway through.
Every prompt box benefitsImage, video, motion graphics, scripting — the picker is one component reused everywhere.

Beats are objects, so any one of them can be re-run alone. That's what turns “swap one thing instead of starting over” from advice into a button.
